# Initial experiments — 2026-09-20

Historical pilot results. The larger 100,000-state experiment and 600,000-round policy evaluation are documented in [release results](release-results.md).

Actual local runs on an NVIDIA RTX 4090, using the pinned English Laya checkpoint. These are small workflow-validation experiments, not demonstrations of optimal blackjack.

## Decision-layer run

500 training states, 100 validation states, 100 held-out test states; 256 reference rollouts per action. Three epochs with a frozen encoder, batch size 4, learning rate 0.0001. Training and evaluation completed in 38.1 seconds after the data and base checkpoint were available.

| Held-out metric | Base, raw | Trained, calibrated |
| --- | ---: | ---: |
| Reference action agreement | 43% | 47% |
| Reference EV regret (units) | 0.18496 | 0.18434 |
| Next-hit probability Brier distance | 0.60908 | 0.20695 |
| Dealer distribution Brier distance | 0.22860 | 0.05199 |
| Teacher-action ECE | 0.21594 | 0.05395 |

The decision-layer run improved probability matching but remained weak at action selection. No claim of profitability follows from these numbers. Calibration metrics use separate validation games; the table reports results on test games.

Full machine-readable configuration, dataset hashes, and metrics: [decision-layer report](results/head-only.json).

## Full-model run

Same fixed dataset and held-out splits. Six epochs, batch size 4, learning rate 0.00002, encoder and decision layers trained. Completed training/calibration/evaluation in 288.8 seconds.

| Held-out metric | Base, raw | Full model, calibrated |
| --- | ---: | ---: |
| Reference action agreement | 43% | 85% |
| Reference EV regret (units) | 0.18496 | 0.01355 |
| Next-hit probability Brier distance | 0.60908 | 0.01185 |
| Dealer distribution Brier distance | 0.22860 | 0.00501 |
| Teacher-action ECE | 0.21594 | 0.06955 |

Reloading the saved checkpoint through the deployed Laya SDK reproduced **85% agreement** and **0.01355 units of reference regret** across all 100 test states. Median inference latency was **19.1 ms** for all three questions in one call, with other local workloads running. This is a measured local result, not a hardware-independent latency promise.

Reports: [full-model training](results/full-model.json), [reloaded inference](results/reloaded-inference.json).

## Realized policy returns

200 independent fresh-shoe rounds per policy; 3 players, 6 decks, S17, 3:2, double after split, surrender, basic tablemates, seed 12345. Reference used 256 rollouts per action. All policies started each round from the same initial seed.

| Policy | Mean net units / round | 95% interval |
| --- | ---: | ---: |
| basic | -0.0425 | [-0.1987, +0.1137] |
| reference | -0.0675 | [-0.2233, +0.0883] |
| laya | -0.0375 | [-0.1992, +0.1242] |

All intervals overlap substantially. This small run verifies the complete evaluation path; it cannot rank the policies reliably or establish an advantage over the house. No rounds were voided. [Full benchmark report](results/benchmark-200.json).

A separate 25-round-per-policy benchmark launched from the dashboard also completed successfully, exercising the browser → API → subprocess → result path.

## Provenance and limitations

The training dataset was generated by the engine at git commit `dcfaac4`. Subsequent replay hardening separated tablemate behavior randomness from shuffle randomness. Existing saved examples and metrics remain unchanged, but regenerated random-tablemate examples on later commits differ. The reports preserve exact dataset hashes; reproduce the initial dataset at that commit to match them.

The 100 test states come from 25 disjoint game seeds and include correlated decisions within games. The sample is small. Reported agreement compares against an approximate, noisy teacher rather than exact optimal play. The full model was a follow-up to the head-only pilot, so a final research-grade comparison should add a new locked evaluation set before further tuning.

Next research steps: a larger independently seeded dataset; more precise action values for close decisions; deeper or exact reference evaluation where feasible; stratification by player count and rule set; and longer held-out return comparisons with appropriate uncertainty.
